The Flow:
1. Admin adds employee (no password)
2. Admin sends invitation email
3. Employee receives email with setup link
4. Employee clicks link and sets password
5. Auto-logged in
6. Can login normally with email + password

Why It's Secure:
• No passwords in email
• Employee sets own password
• Token-based (unique, time-limited, single-use)
• Bcrypt hashing
• JWT authentication
• Industry standard (Slack, GitHub, Google, etc.)

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

Email not received?
  → Check spam folder
  → Verify email address
  → Check SMTP configuration
  → Try resending

Invalid token error?
  → Token expired (7+ days)
  → Wrong link in email
  → Request new invitation

Can't login?
  → Check email and password
  → Check CAPS LOCK
  → Check account status
  → Check browser cache

More detailed troubleshooting in each document!
